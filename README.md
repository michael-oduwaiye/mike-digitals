# Mike Digitals

Mike Digitals is a Nigerian digital services platform providing convenient
access to mobile data and telecom services.

The platform is built to provide customers with a simple, automated experience
from selecting a service through payment and fulfillment.

## What the platform provides

- Mobile data services
- Online payment processing
- Automated service fulfillment
- Transaction tracking
- Administrative tools for managing the platform

## Technology

This project is built with:

- Node.js
- JavaScript
- Paystack
- Gladtidings
- HTML, CSS and JavaScript

## Project Status

Mike Digitals is an actively developed project.

The platform is currently being improved with a focus on:

- Reliability
- Security
- Customer experience
- Transaction monitoring
- Administrative tooling

## Development

This repository contains the source code for the Mike Digitals platform.

Configuration and production credentials are intentionally kept outside the
repository.

## Security

If you discover a security vulnerability, please report it privately rather
than publicly exposing the issue.

Do not submit API keys, passwords, tokens, payment credentials, or other
sensitive information through issues or pull requests.
